# EMI Enchants — Inspect Every Enchantment Before You Anvil

EMI Enchants 9minecraft Mod adds detailed enchantment lookup pages for EMI. It lets you check enchantment costs, item compatibility, and conflicts before spending levels at an anvil. The mod reads directly from the game's registry, so every modded and vanilla enchant shows up with full details. You can view rarity, level requirements, table costs, and loot sources on one clear screen.

Turns every vanilla and modded enchantment into a readable EMI page.

## What this build is

An unofficial rebuild of **Mephodio**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
